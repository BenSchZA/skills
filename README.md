# Claude Code Skills

A collection of my favourite Claude Code skills bundled as git submodules in a single marketplace.

## Included Skills

- **[Superpowers](https://github.com/obra/superpowers)** — A complete software development workflow with brainstorming, TDD, implementation planning, subagent-driven development, and code review.
- **[Obsidian Skills](https://github.com/kepano/obsidian-skills)** — Agent skills for working with Obsidian vaults, including markdown, Bases, JSON Canvas, and the Obsidian CLI.
- **[QMD](https://github.com/tobi/qmd)** — Search and retrieve documents from local markdown knowledge bases using QMD's full-text and vector search.
- **[Minimalist Entrepreneur Skills](https://github.com/slavingia/skills)** — Skills based on *The Minimalist Entrepreneur* by Sahil Lavingia, covering community finding, idea validation, MVPs, pricing, marketing, and more.

## Installation

Add this repo as a plugin marketplace, then install whichever plugins you want:

```sh
/plugin marketplace add BenSchZA/skills
/plugin install superpowers@benscholtz-skills
/plugin install obsidian@benscholtz-skills
/plugin install qmd@benscholtz-skills
/plugin install minimalist-entrepreneur@benscholtz-skills
```
